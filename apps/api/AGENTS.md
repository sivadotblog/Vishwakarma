# apps/api

Python backend. Package `api` lives in `src/api/`, tests in `tests/` (pytest, files `test_*.py`).

- No web framework chosen yet — don't add one without an issue that asks for it.
- Everything is type-checked with `mypy --strict`: annotate all functions, including tests.
- Add dependencies with `uv add --package api <pkg>` (see the `uv` skill).
